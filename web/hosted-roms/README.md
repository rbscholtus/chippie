# Hosted ROMs

These 18 ROMs can't be downloaded from a browser anywhere else, so Chippie hosts
them (README §9.1). All are unmodified files, and each file's SHA-1 matches
chip-8-database.

**From [Zophar's Domain, CHIP-8 public-domain ROMs](https://www.zophar.net/pdroms/chip8.html)**
(the "Super Chip Games Pack" and, for `KALEID`, the "Chip-8 Games Pack"):
`ALIEN`, `ANT`, `BLINKY`, `CAR`, `FIELD`, `JOUST`, `KALEID`, `PIPER`, `RACE`,
`SPACEFIG`, `UBOAT`, `WORM3`.

**From [David Winter's CHIP-8 page](https://www.pong-story.com/chip8/)**, which
offers them as freeware:

- `chp8_220.zip`, his emulator package: `MINES` (Mines!), `SQUARE` (Magic
  Square) and `MAZE` (Super Maze) by David Winter; `DRAGON1` and `DRAGON2`
  (Single Dragon, unfinished) by David Nurser.
- `loopz.zip`: `LOOPZ` (Loopz) by Andreas Daumann.

Credit belongs to the original authors. The `.DOC` files are the authors' own
notes, included unchanged.
