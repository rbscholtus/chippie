# Hosted ROMs

These 12 ROMs can't be downloaded from a browser anywhere else, so Chippie hosts
them (README §9.1). They are unmodified files from
[Zophar's Domain, CHIP-8 public-domain ROMs](https://www.zophar.net/pdroms/chip8.html),
from the "Super Chip Games Pack" and, for `KALEID`, the "Chip-8 Games Pack".
Each file's SHA-1 matches chip-8-database.

Credit belongs to the original authors. `UBOAT.DOC` and `SPACEFIG.DOC` are the
authors' own notes, included unchanged.
